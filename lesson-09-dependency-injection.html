Lesson 9: Dependency Injection (.NET 8 Style)

Dependency injection keeps controllers focused on request handling while services take responsibility for business and data access concerns.

Introduction

ASP.NET Core has a built-in DI container. In .NET 8, we register services directly in Program.cs and request them through constructor injection.

Key Concepts

  • Interfaces define contracts.
  • Service lifetimes include singleton, scoped, and transient.
  • Controllers should depend on abstractions, not concrete details.
  • DI improves testing and maintainability.

Step-by-Step

Define the Service Contract

using TodoMvcApp.Models;

namespace TodoMvcApp.Services;

public interface ITodoService
{
    Task<IReadOnlyList<TodoItem>> GetAllAsync(CancellationToken cancellationToken);
    Task AddAsync(TodoItem item, CancellationToken cancellationToken);
}

Create the Service Implementation

using TodoMvcApp.Data;
using TodoMvcApp.Models;

namespace TodoMvcApp.Services;

public sealed class InMemoryTodoService : ITodoService
{
    public Task<IReadOnlyList<TodoItem>> GetAllAsync(CancellationToken cancellationToken) =>
        TodoStore.GetAllAsync(cancellationToken);

    public Task AddAsync(TodoItem item, CancellationToken cancellationToken) =>
        TodoStore.AddAsync(item, cancellationToken);
}

Register in Program.cs

var builder = WebApplication.CreateBuilder(args);

builder.Services.AddControllersWithViews();
builder.Services.AddSingleton<ITodoService, InMemoryTodoService>();

var app = builder.Build();

Inject into the Controller

public sealed class TodoController : Controller
{
    private readonly ITodoService _todoService;

    public TodoController(ITodoService todoService)
    {
        _todoService = todoService;
    }

    public async Task<IActionResult> Index(CancellationToken cancellationToken)
    {
        var items = await _todoService.GetAllAsync(cancellationToken);
        return View(items);
    }
}

Summary
