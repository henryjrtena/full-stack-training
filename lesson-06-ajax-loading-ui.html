AJAX

Lesson 6: AJAX + Loading UI

This lesson submits the Todo form without a full page refresh and adds a small loading experience so users know the app is working.

Introduction

AJAX is useful when you want to submit or refresh small parts of the interface without navigating away from the current page. jQuery keeps the code simple for an MVC application.

Key Concepts

  • Intercept form submit events with jQuery.
  • Send form data to an MVC action using $.ajax.
  • Disable the submit button to prevent duplicate posts.
  • Show and hide a loading indicator around the request.

Step-by-Step

Controller Returning JSON

[HttpPost]
[ValidateAntiForgeryToken]
public async Task<IActionResult> CreateAjax(
    TodoItem item,
    CancellationToken cancellationToken)
{
    if (!ModelState.IsValid)
    {
        return BadRequest(ModelState);
    }

    await Task.Delay(300, cancellationToken);
    return Json(new { success = true, message = "Todo created." });
}

Form Markup

<form id="todo-form" asp-action="CreateAjax" method="post">
    @Html.AntiForgeryToken()
    <input asp-for="Title" class="form-control" />
    <button id="submit-button" type="submit">Save</button>
    <span id="loading-indicator" style="display:none;">Saving...</span>
</form>

<div id="result-message"></div>

jQuery AJAX Script

<script>
$(function () {
    $("#todo-form").on("submit", function (event) {
        event.preventDefault();

        const $form = $(this);
        const $button = $("#submit-button");
        const $loading = $("#loading-indicator");
        const $message = $("#result-message");

        $button.prop("disabled", true);
        $loading.show();
        $message.text("");

        $.ajax({
            url: $form.attr("action"),
            type: "POST",
            data: $form.serialize()
        }).done(function (response) {
            $message.text(response.message);
            $form.trigger("reset");
        }).fail(function () {
            $message.text("Unable to save the todo item.");
        }).always(function () {
            $button.prop("disabled", false);
            $loading.hide();
        });
    });
});
</script>
