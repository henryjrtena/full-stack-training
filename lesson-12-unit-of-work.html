Transactions

Lesson 12: Unit of Work

Unit of Work coordinates multiple repository actions so they succeed or fail together as one logical transaction.

Introduction

If a feature touches several tables or requires a sequence of updates, a Unit of Work can provide transaction boundaries and a single commit point.

Key Concepts

  • Use Unit of Work when one user operation spans multiple writes.
  • Transactions help maintain consistency.
  • EF Core already behaves like a unit of work through DbContext.
  • With Dapper, you can manage a shared connection and transaction explicitly.

Step-by-Step

Define the Contract

public interface IUnitOfWork
{
    ITodoRepository Todos { get; }
    Task BeginAsync(CancellationToken cancellationToken);
    Task CommitAsync(CancellationToken cancellationToken);
    Task RollbackAsync(CancellationToken cancellationToken);
}

Example Dapper-Oriented Shape

public sealed class SqlUnitOfWork : IUnitOfWork, IAsyncDisposable
{
    private readonly SqlConnection _connection;
    private SqlTransaction? _transaction;

    public SqlUnitOfWork(IConfiguration configuration)
    {
        var connectionString = configuration.GetConnectionString("TodoDb")
            ?? throw new InvalidOperationException("Missing TodoDb connection string.");
        _connection = new SqlConnection(connectionString);
        Todos = new TransactionalTodoRepository(_connection, () => _transaction);
    }

    public ITodoRepository Todos { get; }

    public async Task BeginAsync(CancellationToken cancellationToken)
    {
        await _connection.OpenAsync(cancellationToken);
        _transaction = (SqlTransaction)await _connection.BeginTransactionAsync(cancellationToken);
    }

    public Task CommitAsync(CancellationToken cancellationToken) =>
        _transaction!.CommitAsync(cancellationToken);

    public Task RollbackAsync(CancellationToken cancellationToken) =>
        _transaction!.RollbackAsync(cancellationToken).AsTask();

    public ValueTask DisposeAsync() => _connection.DisposeAsync();
}

Use It Carefully

await _unitOfWork.BeginAsync(cancellationToken);
try
{
    await _unitOfWork.Todos.AddAsync(item, cancellationToken);
    await _auditRepository.WriteEntryAsync("Todo created", cancellationToken);
    await _unitOfWork.CommitAsync(cancellationToken);
}
catch
{
    await _unitOfWork.RollbackAsync(cancellationToken);
    throw;
}
