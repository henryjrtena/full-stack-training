LINQ Bridge

Lesson 8.1: LINQ Hands-On in a Controller

Before moving into dependency injection, this bridge lesson introduces LINQ using the same in-memory Todo idea from Lesson 8. We will query a fake Todo list inside a controller and practice common LINQ operations with exact expected output.

Introduction

LINQ stands for Language Integrated Query. It lets you query collections in C# using readable method chains or query syntax. In ASP.NET Core MVC, LINQ is everywhere: filtering data, sorting records, selecting fields, grouping items, and shaping data before passing it to a view or API response.

Key Concepts

  • Where filters items.
  • Select projects items into a new shape.
  • OrderBy and OrderByDescending sort data.
  • FirstOrDefault, Any, and Count help inspect collections.
  • LINQ is especially useful with in-memory collections, EF Core, and API responses.

Step-by-Step

Create Fake Todo Data in a Controller

using Microsoft.AspNetCore.Mvc;

namespace TodoMvcApp.Controllers;

public sealed class LinqDemoController : Controller
{
    private static readonly List<TodoItem> Todos =
    [
        new() { Id = 1, Title = "Learn MVC", IsCompleted = false, Priority = 2 },
        new() { Id = 2, Title = "Write controller", IsCompleted = true, Priority = 3 },
        new() { Id = 3, Title = "Build view", IsCompleted = false, Priority = 1 },
        new() { Id = 4, Title = "Add validation", IsCompleted = true, Priority = 4 },
        new() { Id = 5, Title = "Practice LINQ", IsCompleted = false, Priority = 5 }
    ];
}

public sealed class TodoItem
{
    public int Id { get; set; }
    public string Title { get; set; } = string.Empty;
    public bool IsCompleted { get; set; }
    public int Priority { get; set; }
}

This fake list gives us a predictable dataset. That matters because every exercise below includes exact expected output.

Common LINQ Functions

var openItems = Todos.Where(x => !x.IsCompleted);
var titles = Todos.Select(x => x.Title);
var sorted = Todos.OrderByDescending(x => x.Priority);
var first = Todos.FirstOrDefault();
var hasCompleted = Todos.Any(x => x.IsCompleted);
var total = Todos.Count();

These are some of the most frequently used LINQ methods in MVC applications. We will now practice them in controller actions.

Hands-On Activities

Exercise 1: Use Select to Return Titles Only

Show Sample Solution 
public IActionResult Exercise1()
{
    var result = Todos
        .Select(x => x.Title)
        .ToList();

    return Json(result);
}

Exact Output:

[
  "Learn MVC",
  "Write controller",
  "Build view",
  "Add validation",
  "Practice LINQ"
]

Exercise 2: Use Where to Return Open Todo Items

Show Sample Solution 
public IActionResult Exercise2()
{
    var result = Todos
        .Where(x => !x.IsCompleted)
        .Select(x => x.Title)
        .ToList();

    return Json(result);
}

Exact Output:

[
  "Learn MVC",
  "Build view",
  "Practice LINQ"

Exercise 3: Use OrderByDescending for Priority

Show Sample Solution 
public IActionResult Exercise3()
{
    var result = Todos
        .OrderByDescending(x => x.Priority)
        .Select(x => new { x.Title, x.Priority })
        .ToList();

    return Json(result);
}

Exact Output:

[
  { "title": "Practice LINQ", "priority": 5 },
  { "title": "Add validation", "priority": 4 },
  { "title": "Write controller", "priority": 3 },
  { "title": "Learn MVC", "priority": 2 },
  { "title": "Build view", "priority": 1 }
]

Exercise 4: Combine Where and OrderByDescending

Show Sample Solution 
public IActionResult Exercise4()
{
    var result = Todos
        .Where(x => !x.IsCompleted)
        .OrderByDescending(x => x.Priority)
        .Select(x => new { x.Title, x.Priority })
        .ToList();

    return Json(result);
}

Exact Output:

[
  { "title": "Practice LINQ", "priority": 5 },
  { "title": "Learn MVC", "priority": 2 },
  { "title": "Build view", "priority": 1 }
]

Exercise 5: Use Select to Shape Custom Output

Show Sample Solution 
public IActionResult Exercise5()
{
    var result = Todos
        .Select(x => new
        {
            x.Id,
            Summary = $"{x.Title} - Priority {x.Priority}"
        })
        .ToList();

    return Json(result);
}

Exact Output:

[
  { "id": 1, "summary": "Learn MVC - Priority 2" },
  { "id": 2, "summary": "Write controller - Priority 3" },
  { "id": 3, "summary": "Build view - Priority 1" },
  { "id": 4, "summary": "Add validation - Priority 4" },
  { "id": 5, "summary": "Practice LINQ - Priority 5" }
]

Extra LINQ Functions Worth Knowing

Count, Any, and FirstOrDefault

public IActionResult ExtraExamples()
{
    var total = Todos.Count();
    var hasCompleted = Todos.Any(x => x.IsCompleted);
    var firstHighPriority = Todos.FirstOrDefault(x => x.Priority >= 4);

    return Json(new
    {
        Total = total,
        HasCompleted = hasCompleted,
        FirstHighPriority = firstHighPriority?.Title
    });
}

Exact Output:

{
  "total": 5,
  "hasCompleted": true,
  "firstHighPriority": "Add validation"
}

Practice Activity

Create a controller named LinqPracticeController and copy the same fake Todo list. Then try the following exercises on your own before checking the expected output.

  1. Select only the Id values.
  2. Filter only completed todo items.
  3. Sort all todo items by Title in ascending order.
  4. Filter items with Priority >= 3.
  5. Select a new object with only Title and IsCompleted.

For classroom practice, ask students to predict the output before running the action. LINQ becomes much easier once they can read a query and mentally picture the resulting collection.

Summary

LINQ gives you a powerful, readable way to query collections inside controllers. In this bridge lesson, you practiced Select, Where, and OrderByDescending using exact outputs on a fake Todo list. That foundation will help a lot once the course moves from static data into injected services and repositories.
