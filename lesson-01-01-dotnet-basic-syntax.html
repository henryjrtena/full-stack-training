ASP.NET Core MVC Todo Application (.NET 8)

Lesson 1.1: .NET Basic Coding Syntax and Modern .NET 8 Syntax

Before we build the Todo application, it helps to get comfortable with everyday C# syntax and the modern coding style you will see throughout a .NET 8 project. This lesson bridges classic C# basics with the cleaner syntax patterns used in current ASP.NET Core applications.

Introduction

C# has grown over many versions, and .NET 8 projects often use newer, more compact syntax. You still need the basics like variables, conditionals, loops, classes, and methods, but you also need to recognize features like top-level style hosting, collection expressions, primary constructors, file-scoped namespaces, and async-first coding patterns.

Key Concepts

  • Basic C# syntax includes variables, methods, conditionals, loops, and classes.
  • Modern .NET code prefers concise syntax when it improves readability.
  • File-scoped namespaces reduce indentation noise.
  • async and await are standard for I/O and web development.
  • .NET 8 applications use the minimal hosting model in Program.cs.

Step-by-Step

Basic Variables and Control Flow

string title = "Buy groceries";
int priority = 2;
bool isCompleted = false;

if (!isCompleted && priority > 1)
{
    Console.WriteLine("This todo needs attention.");
}
else
{
    Console.WriteLine("This todo can wait.");
}

This is standard C# syntax you will see everywhere. Variables are strongly typed, conditions use boolean expressions, and code blocks use braces.

Methods and Classes

public sealed class TodoItem
{
    public int Id { get; set; }
    public string Title { get; set; } = string.Empty;
    public bool IsCompleted { get; set; }

    public string GetStatus()
    {
        return IsCompleted ? "Done" : "Open";
    }
}

Classes group related data and behavior. Properties store values, and methods provide logic that works with those values.

Modern File-Scoped Namespace Syntax

namespace TodoMvcApp.Models;

public sealed class TodoItem
{
    public int Id { get; set; }
    public string Title { get; set; } = string.Empty;
}

Older C# code wrapped the entire file inside braces after the namespace declaration. File-scoped namespaces are cleaner and are common in modern .NET projects.

Object Initializers and Target-Typed new

TodoItem item = new()
{
    Id = 1,
    Title = "Study ASP.NET Core MVC",
    IsCompleted = false
};

When the type is already known on the left side, new() avoids repeating the type name.

Collection Expressions in Modern C#

List<TodoItem> items =
[
    new() { Id = 1, Title = "Learn routing" },
    new() { Id = 2, Title = "Build create form" }
];

This compact collection expression syntax is a modern addition and fits nicely in .NET 8-era codebases.

Expression-Bodied Members

public string GetSummary() => $"{Id}: {Title}";

Short one-line members are often written with expression-bodied syntax to reduce boilerplate.

Primary Constructor Style

public sealed class TodoService(ILogger<TodoService> logger)
{
    public void LogCreate(TodoItem item)
    {
        logger.LogInformation("Created todo {Title}", item.Title);
    }
}

Primary constructors are a newer C# feature that work well for dependency injection and simple service classes.

Async and Await

public async Task SaveAsync(TodoItem item, CancellationToken cancellationToken)
{
    await Task.Delay(100, cancellationToken);
    Console.WriteLine($"Saved {item.Title}");
}

In web apps, async methods are preferred for database calls, API calls, file access, and anything else that waits on I/O.

Modern .NET 8 Program.cs Syntax

var builder = WebApplication.CreateBuilder(args);

builder.Services.AddControllersWithViews();

var app = builder.Build();

app.UseHttpsRedirection();
app.UseStaticFiles();
app.UseRouting();

app.MapControllerRoute(
    name: "default",
    pattern: "{controller=Todo}/{action=Index}/{id?}");

app.Run();

This is the standard .NET 8 application startup style. It replaces the older Startup.cs approach and is the pattern used throughout this course.

Older Style vs Newer Style

// Older style
namespace TodoMvcApp.Models
{
    public class TodoItem
    {
        public string Title { get; set; }
    }
}

// Newer style
namespace TodoMvcApp.Models;

public sealed class TodoItem
{
    public string Title { get; set; } = string.Empty;
}

The newer style is not just shorter. It also reflects current conventions around null safety, immutability where appropriate, and more readable project files.

Summary

You now have a foundation in both traditional C# syntax and the modern coding style used in .NET 8 applications. That means the code in the rest of this MVC Todo course should feel much more approachable.
