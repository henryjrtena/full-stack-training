Lesson 15: Global Exception Handling

Centralized error handling keeps controller code cleaner and ensures the app responds consistently when something goes wrong.

Introduction

Instead of wrapping every controller action in repeated try/catch blocks, we can use middleware to log unexpected failures and produce friendly responses. We can also treat cancellations as a normal control flow signal.

Key Concepts

  • Middleware runs for every request.
  • ILogger records exception details.
  • OperationCanceledException should usually not be logged as an application error.
  • Production environments should avoid exposing raw stack traces.

Step-by-Step

Create Middleware

public sealed class GlobalExceptionMiddleware(
    RequestDelegate next,
    ILogger<GlobalExceptionMiddleware> logger)
{
    public async Task InvokeAsync(HttpContext context)
    {
        try
        {
            await next(context);
        }
        catch (OperationCanceledException) when (context.RequestAborted.IsCancellationRequested)
        {
            logger.LogInformation("Request was cancelled by the client.");
            context.Response.StatusCode = 499;
        }
        catch (Exception exception)
        {
            logger.LogError(exception, "Unhandled exception while processing {Path}", context.Request.Path);
            context.Response.StatusCode = StatusCodes.Status500InternalServerError;
            context.Response.ContentType = "application/json";
            await context.Response.WriteAsJsonAsync(new
            {
                error = "An unexpected error occurred."
            });
        }
    }
}

Register the Middleware

var app = builder.Build();

app.UseMiddleware<GlobalExceptionMiddleware>();
app.UseHttpsRedirection();
app.UseStaticFiles();
app.UseRouting();

Use ILogger in a Controller

public sealed class TodoController(
    ITodoRepository repository,
    ILogger<TodoController> logger) : Controller
{
    public async Task<IActionResult> Index(CancellationToken cancellationToken)
    {
        logger.LogInformation("Loading todo list.");
        var items = await repository.GetAllAsync(cancellationToken);
        return View(items);
    }
}

Summary

Global exception middleware keeps failure handling consistent and reduces repetitive code in MVC controllers. Next we will verify the app with testing strategies for CRUD, validation, and cancellation scenarios.
