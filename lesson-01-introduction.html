ASP.NET Core MVC Todo Application (.NET 8)

Lesson 1: Introduction

This course builds a complete Todo application with ASP.NET Core MVC on .NET 8. We will start with the MVC architecture, then move from simple in-memory storage to Dapper and Entity Framework Core, while keeping everything aligned with modern Program.cs and minimal hosting patterns.

Introduction

ASP.NET Core MVC is a server-side web framework for building maintainable applications with clear separation between user interface, application flow, and domain data. In .NET 8, the preferred setup uses the minimal hosting model in Program.cs instead of the older Startup.cs file.

Key Concepts

  • Model represents Todo data and validation rules.
  • View renders Razor pages for listing and editing todos.
  • Controller handles requests, coordinates services, and returns views or JSON.
  • .NET 8 uses WebApplication.CreateBuilder(args) and builder.Build().
  • Async code and cancellation support help the app remain responsive.

What We Are Building

Application Features

Our Todo app will list tasks, create new tasks, mark tasks complete, edit existing tasks, and delete items. Early lessons use a simple store so we can focus on MVC, then later lessons introduce dependency injection, repositories, Dapper, EF Core, testing, and deployment.

MVC Request Flow

A browser requests /Todo. The TodoController calls application logic, loads Todo items, and returns a Razor view. The view displays the items with HTML generated on the server.

Browser Request
    -> Routing
    -> TodoController
    -> Model / Service / Repository
    -> Razor View
    -> HTML Response

Preview of Modern .NET 8 Hosting

var builder = WebApplication.CreateBuilder(args);

builder.Services.AddControllersWithViews();

var app = builder.Build();

app.UseHttpsRedirection();
app.UseStaticFiles();
app.UseRouting();
app.MapControllerRoute(
    name: "default",
    pattern: "{controller=Todo}/{action=Index}/{id?}");

app.Run();

Summary

ASP.NET Core MVC gives us a clear structure for building a web application, and .NET 8 simplifies startup with a single Program.cs entry point. Our Todo app will be the thread that connects every lesson from presentation to persistence and deployment.
