Resilience

Lesson 7: CancellationToken

Cancellation is an important part of modern .NET applications. If the client disconnects or the browser aborts a request, ASP.NET Core can signal that the work should stop.

Introduction

CancellationToken helps your app avoid wasting time on work the user no longer needs. This matters for slow database calls, long calculations, or AJAX requests that the user cancels.

Key Concepts

  • ASP.NET Core binds a request cancellation token automatically.
  • Pass the token to async APIs like Dapper, EF Core, and Task.Delay.
  • JavaScript can abort an active request if the user changes their mind.
  • Cancellation should be logged differently from real application failures.

Step-by-Step

Controller Action with Cancellation

[HttpPost]
public async Task<IActionResult> CreateAjax(
    TodoItem item,
    CancellationToken cancellationToken)
{
    if (!ModelState.IsValid)
    {
        return BadRequest(ModelState);
    }

    await Task.Delay(TimeSpan.FromSeconds(5), cancellationToken);
    return Json(new { success = true, message = "Saved after delay." });
}

Abort a jQuery Request

<script>
let currentRequest;

$("#todo-form").on("submit", function (event) {
    event.preventDefault();

    if (currentRequest) {
        currentRequest.abort();
    }

    currentRequest = $.ajax({
        url: $(this).attr("action"),
        type: "POST",
        data: $(this).serialize()
    });
});

$("#cancel-button").on("click", function () {
    if (currentRequest) {
        currentRequest.abort();
    }
});
</script>

Service Example

public async Task AddAsync(TodoItem item, CancellationToken cancellationToken)
{
    await Task.Delay(250, cancellationToken);
    _items.Add(item);
}

Handling OperationCanceledException

try
{
    await _todoService.AddAsync(item, cancellationToken);
}
catch (OperationCanceledException)
{
    return StatusCode(499);
}
