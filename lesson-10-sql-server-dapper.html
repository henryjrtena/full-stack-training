Lesson 10: SQL Server + Dapper

Dapper is a lightweight micro-ORM that works very well when you want direct SQL control with minimal overhead.

Introduction

Now that our controller depends on abstractions, we can switch the backing store to SQL Server. We will use Microsoft.Data.SqlClient, Dapper async APIs, and the built-in secret store for local development.

Key Concepts

  • Store connection strings in secrets.json during local development.
  • Use Microsoft.Data.SqlClient for SQL Server connections.
  • Use QueryAsync and ExecuteAsync with cancellation-aware command definitions.
  • Keep SQL in the repository or service layer, not in controllers.

Step-by-Step

Create the Table

CREATE TABLE dbo.TodoItems
(
    Id INT IDENTITY(1,1) PRIMARY KEY,
    Title NVARCHAR(120) NOT NULL,
    Description NVARCHAR(500) NULL,
    DueDate DATE NULL,
    IsCompleted BIT NOT NULL DEFAULT 0
);

Configure the Secret

{
  "ConnectionStrings": {
    "TodoDb": "Server=(localdb)\\MSSQLLocalDB;Database=TodoMvcApp;Trusted_Connection=True;TrustServerCertificate=True;"
  }
}

Dapper Repository

using Dapper;
using Microsoft.Data.SqlClient;
using TodoMvcApp.Models;

namespace TodoMvcApp.Data;

public sealed class DapperTodoRepository
{
    private readonly string _connectionString;

    public DapperTodoRepository(IConfiguration configuration)
    {
        _connectionString = configuration.GetConnectionString("TodoDb")
            ?? throw new InvalidOperationException("Missing TodoDb connection string.");
    }

    public async Task<IReadOnlyList<TodoItem>> GetAllAsync(CancellationToken cancellationToken)
    {
        await using var connection = new SqlConnection(_connectionString);
        await connection.OpenAsync(cancellationToken);

        var command = new CommandDefinition(
            "SELECT Id, Title, Description, DueDate, IsCompleted FROM dbo.TodoItems ORDER BY Id DESC",
            cancellationToken: cancellationToken);

        var items = await connection.QueryAsync<TodoItem>(command);
        return items.AsList();
    }

    public async Task AddAsync(TodoItem item, CancellationToken cancellationToken)
    {
        const string sql = """
            INSERT INTO dbo.TodoItems (Title, Description, DueDate, IsCompleted)
            VALUES (@Title, @Description, @DueDate, @IsCompleted);
            """;

        await using var connection = new SqlConnection(_connectionString);
        await connection.OpenAsync(cancellationToken);

        var command = new CommandDefinition(sql, item, cancellationToken: cancellationToken);
        await connection.ExecuteAsync(command);
    }
}

Register the Repository

builder.Services.AddScoped<DapperTodoRepository>();

Summary

Dapper gives us direct SQL access without abandoning the async and DI patterns established earlier. Next we will formalize this shape with a repository interface and cleaner separation of concerns.
