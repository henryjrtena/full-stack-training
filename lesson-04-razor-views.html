Presentation Layer

Lesson 4: Razor Views

Razor views combine HTML with C# expressions, making it easy to render lists, forms, and validation messages in a strongly typed MVC application.

Introduction

Our Todo application needs a list page and a form page. We will build both with strongly typed Razor views and tag helpers for clean markup.

Key Concepts

  • Use @model to strongly type a Razor view.
  • Loop through collections with standard C# syntax.
  • Use tag helpers like asp-for, asp-action, asp-controller, and asp-route-*.
  • Keep layout and form markup clear and readable.

Step-by-Step

Index View

@model IReadOnlyList<TodoMvcApp.Models.TodoItem>

@{
    ViewData["Title"] = "Todo List";
}

<h1>Todo List</h1>
<p><a asp-action="Create" class="btn btn-primary">Add Todo</a></p>

<table class="table">
    <thead>
        <tr>
            <th>Title</th>
            <th>Due Date</th>
            <th>Status</th>
        </tr>
    </thead>
    <tbody>
    @foreach (var item in Model)
    {
        <tr>
            <td>@item.Title</td>
            <td>@item.DueDate?.ToString("yyyy-MM-dd")</td>
            <td>@(item.IsCompleted ? "Done" : "Open")</td>
        </tr>
    }
    </tbody>
</table>

Create View with Tag Helpers

@model TodoMvcApp.Models.TodoItem

@{
    ViewData["Title"] = "Create Todo";
}

<h1>Create Todo</h1>

<form asp-action="Create" method="post">
    @Html.AntiForgeryToken()

    <div class="mb-3">
        <label asp-for="Title" class="form-label"></label>

    <div class="mb-3">

    </div>

    <div class="mb-3">
        <label asp-for="DueDate" class="form-label"></label>

</form>

Other Common HTML Tag Helpers

@model TodoMvcApp.Models.TodoItem

Razor supports many HTML tag helpers beyond simple form binding. Anchor tag helpers use asp-controller, asp-action, and asp-route-* to generate links. Form tag helpers help build safe post forms, while label, input, select, validation, partial, and environment tag helpers keep markup more maintainable.

Classic HTML Helper Style

@model TodoMvcApp.ViewModels.TodoFormViewModel

@Html.LabelFor(model => model.Title, new { @class = "form-label" })
@Html.TextBoxFor(model => model.Title, new { @class = "form-control" })
@Html.ValidationMessageFor(model => model.Title, "", new { @class = "text-danger" })

@Html.LabelFor(model => model.Status, new { @class = "form-label" })
@Html.DropDownListFor(
    model => model.Status,
    Model.StatusOptions,
    "-- Select status --",
    new { @class = "form-select" })

@Html.ValidationSummary(false, "", new { @class = "text-danger" })

Before tag helpers became the preferred Razor style, MVC views often used HTML helpers such as LabelFor, TextBoxFor, ValidationMessageFor, and DropDownListFor. These helpers are still valid in ASP.NET Core MVC and you will still see them in many existing projects.

HTML Helper vs Tag Helper

// HTML helper style
@Html.DropDownListFor(
    model => model.Status,
    Model.StatusOptions,
    "-- Select status --",
    new { @class = "form-select" })

// Tag helper style
<select asp-for="Status" asp-items="Model.StatusOptions" class="form-select">
    <option value="">-- Select status --</option>
</select>

The HTML helper style is method-based and lives inside C# expressions. The tag helper style feels more like regular HTML and is usually easier to read in modern Razor views. Both approaches are supported, so it is useful to recognize both when reading or maintaining MVC code.

What These Tag Helpers Do

  • asp-controller chooses which controller the generated URL targets.
  • asp-action points to the action method for the link or form.
  • asp-route-id and similar attributes pass route values into generated URLs.
  • asp-for binds elements like input, label, and select to model properties.
  • asp-validation-for renders validation messages for a property.
  • partial renders a reusable partial view.
  • environment conditionally renders markup based on the current hosting environment.

Controller Feeding the Views

public IActionResult Index()
{
    var items = Array.Empty<TodoItem>();
    return View(items);
}

[HttpGet]
public IActionResult Create()
{
    return View(new TodoItem());
}
